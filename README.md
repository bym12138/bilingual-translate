# 双语翻译

一个极简的 Chrome 双语翻译扩展，「沉浸式翻译」的轻量替代。只做两件事：

1. **网页双语对照**：每段原文下面插入中文译文
2. **YouTube 双语字幕**：原文 + 中文两行字幕，放在同一块阴影里

## 和沉浸式翻译相比

- **轻**：全部代码约 400 行，没有框架，也不用构建，加载就能用，几分钟就能读完
- **零配置**：不用注册账号，不用申请 API Key，按 `⌥A` 就翻译
- **干净**：不收集任何数据，除了谷歌翻译接口不连别的服务，没有广告，也没有会员
- **YouTube 字幕更顺**：直接截获完整的字幕文件，自动生成的字幕先拼成整句再翻，不会一个词一个词地跳
- **懂网站**：X 上只翻推文，GitHub 上只翻 README 和评论，不碰按钮和文件名
- **好改**：换目标语言、换翻译引擎，都只要改一个地方

## 安装

1. 下载本仓库（`git clone` 或点 Code → Download ZIP 后解压）
2. Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹
4. 建议在工具栏拼图菜单里把扩展图标固定出来

需要能访问谷歌。

## 用法

| 操作 | 效果 |
|---|---|
| 点扩展图标 / 按 `⌥A` | 翻译当前网页，图标变**粉色**；再按一次还原，图标变回灰色 |
| YouTube 打开 CC 字幕 | 自动显示双语字幕，无需按键 |

- 只翻译滚动到附近的内容，后加载的内容（无限滚动、评论区）会自动补翻
- 已经是中文的段落、`@用户名`、链接、导航栏 / 菜单不翻
- X（Twitter）上只翻推文正文和用户简介
- GitHub 上只翻 README、Issue/PR 评论、Release 说明、Wiki 和仓库简介
- 快捷键没反应：去 `chrome://extensions/shortcuts` 手动设置

## 工作原理

**翻译接口**：用的是 Chrome 自带网页翻译背后的谷歌接口（`translate-pa.googleapis.com`），免费、支持一次翻多段。请求会分批、并发、缓存，失败自动重试一次。

**网页翻译**：不看标签名，而是对每处文字往外找「最近的非行内元素」当作一段（按浏览器实际显示判断），所以 YouTube 这类满是自定义标签的网站也能识别。用 `IntersectionObserver` 只翻可见区域附近的段落，用 `MutationObserver` 补翻动态加载的内容。

**YouTube 字幕**：不去抓页面上显示的字幕文字，而是截获播放器下载的完整字幕文件（`/api/timedtext`），一次性整理、从当前播放位置开始优先翻译，再自己画在播放器上。所以译文是整句的，不会逐词跳动。

## 文件说明

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展配置：权限、快捷键、图标、注入哪些脚本 |
| `background.js` | 调用翻译接口；处理图标点击和快捷键，切换图标颜色 |
| `content.js` | 网页双语对照：找出页面上的「段落」，滚到附近时翻译并插入译文 |
| `youtube-hook.js` | 在 YouTube 页面环境里截获播放器请求的字幕数据 |
| `youtube.js` | 整理字幕（自动生成的字幕逐词拼成整句）、翻译、绘制双语字幕、隐藏原生字幕 |
| `style.css` | 网页译文样式 + YouTube 字幕样式 |
| `icons/` | `off-*.png` 灰色（默认），`on-*.png` 粉色（翻译中） |

## 自定义

| 想改什么 | 在哪改 |
|---|---|
| 目标语言（如英文、日文） | `background.js` 顶部 `TARGET_LANG`；同时注意 `content.js` 里 `isChinese` 会跳过中文段落、`youtube.js` 里中文字幕只显示原文 |
| 换翻译引擎（付费 API / 本地模型） | 只改 `background.js` 的 `requestBatch`：输入一组文字，返回同样顺序的一组译文即可 |
| 快捷键 | `manifest.json` 的 `commands` |
| 网页译文颜色 | `style.css` 的 `.bt-trans`（`color-mix` 里的百分比越小越明显） |
| 字幕样式（阴影、译文黄色、位置） | `style.css` 的 `.bt-yt-sub` 系列 |
| 字幕字号 | `youtube.js` 的 `render()` 里 `player.clientHeight * 0.04` |
| 不想翻译的区域 | `content.js` 顶部 `SKIP` 列表 |
| 某网站只翻特定内容（像 X 那样） | `content.js` 顶部 `SITE_ONLY`，按域名配置选择器（选中的元素整块当一段翻） |
| 某网站只翻特定区域（像 GitHub 那样） | `content.js` 顶部 `SITE_SCOPE`，按域名配置选择器（区域内照常按段落翻） |

改完代码后，在 `chrome://extensions` 点扩展卡片上的刷新按钮，**再刷新正在用的网页**，新代码才会生效。

## 已知限制

- 翻译接口来自 Chrome 内置翻译，非官方公开 API，谷歌可能随时调整或限制；访问不了谷歌时会显示「翻译失败：原因」
- YouTube 长评论默认折叠，要点「展开」才能看到译文
- 已翻译的段落如果之后被网站改了文字，译文不会跟着更新（关掉再开一次即可）
- 更新扩展后，已打开的旧页面要刷新才能用
